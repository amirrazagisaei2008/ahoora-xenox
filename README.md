# پنل اهورا + پنل ادمین مدیریت رمز سراسری (Cloudflare Pages + KV)

این پروژه شامل **پنل اصلی اهورا** (`index.html`)، **پنل ادمین اختصاصی** (`/admin`) و **بک‌اند Cloudflare Pages Functions** (`functions/api/[[path]].js`) است تا رمز ورود پنل اصلی به‌صورت امن (هش‌شده با `PBKDF2-SHA256`) در **Cloudflare KV** ذخیره شود و هر تغییر رمز توسط ادمین بلافاصله برای **همه کاربران** اعمال شده و نشست کاربران آنلاین قبلی فوراً باطل شود.

---

## آدرس صفحات

- **پنل اصلی کاربران:** `/`
- **پنل ادمین:** `/admin`

## رمزهای پیش‌فرض (در اولین اجرا)

اگر متغیر محیطی تنظیم نکرده باشید، در اولین اجرا این رمزها به‌طور خودکار هش شده و در KV ذخیره می‌شوند:

- **رمز پیش‌فرض پنل اصلی:** `AT_SERVER`
- **رمز پیش‌فرض پنل ادمین:** `AT_ADMIN`

> **توصیه امنیتی:** بلافاصله پس از اولین ورود به `/admin`، رمز پنل ادمین را تغییر دهید.

---

## راهنمای راه‌اندازی روی Cloudflare Pages

### ۱) اتصال مخزن GitHub به Cloudflare Pages
1. وارد داشبورد Cloudflare شوید و به بخش **Workers & Pages → Create → Pages → Connect to Git** بروید.
2. مخزن `ahoora-xenox` را انتخاب کنید.
3. تنظیمات بیلد را به شکل زیر بگذارید:
   - **Framework preset:** `None`
   - **Build command:** *(خالی بگذارید)*
   - **Build output directory:** `/` (یا `.`)
4. روی **Save and Deploy** بزنید.

### ۲) ساخت و اتصال Cloudflare KV (الزامی)
1. در داشبورد Cloudflare به مسیر **Storage & Databases → KV** بروید و یک Namespace جدید بسازید (مثلاً با نام `AHOORA_KV`).
2. وارد پروژه Pages خود شوید و به مسیر **Settings → Functions → KV namespace bindings** بروید.
3. یک Binding جدید (برای **Production** و در صورت نیاز **Preview**) با این مشخصات دقیق اضافه کنید:
   - **Variable name:** `AHOORA_KV` *(دقیقاً با همین نام و حروف بزرگ)*
   - **KV namespace:** همان Namespace که ساختید.
4. پس از ذخیره، یک بار از تب **Deployments** گزینه **Retry deployment** (یا یک Commit جدید) را اجرا کنید تا Binding روی دیپلوی جدید فعال شود.

### ۳) متغیرهای محیطی اختیاری (توصیه‌شده)
در مسیر **Settings → Environment variables** می‌توانید این متغیرها را (ترجیحاً به صورت Encrypted / Secret) تنظیم کنید:

| نام متغیر | توضیح | مقدار پیش‌فرض |
| --- | --- | --- |
| `INITIAL_PANEL_PASSWORD` | رمز اولیه پنل اصلی (فقط اگر هنوز در KV ثبت نشده باشد) | `AT_SERVER` |
| `INITIAL_ADMIN_PASSWORD` | رمز اولیه پنل ادمین (فقط اگر هنوز در KV ثبت نشده باشد) | `AT_ADMIN` |
| `SESSION_SECRET` | کلید امضای نشست‌ها (حداقل ۱۶ کاراکتر تصادفی) | ساخت خودکار در KV |

## امکانات امنیتی

- **حذف کامل رمز از سورس صفحه:** هیچ رمزی داخل `index.html` وجود ندارد؛ بررسی رمز فقط سمت سرور انجام می‌شود.
- **ذخیره امن رمزها:** رمزها هرگز به‌صورت متن خام ذخیره نمی‌شوند (الگوریتم `PBKDF2-SHA256` با ۱۵ هزار تکرار بهینه‌شده برای محدودیت CPU پلن رایگان کلودفلر و Salt یکتا).
- **خروج فوری همه کاربران پس از تغییر رمز:** هر تغییر رمز، نسخه نشست (`version` و `epoch`) را در KV تغییر می‌دهد؛ در نتیجه نشست همه کاربران آنلاین بلافاصله باطل شده و با پیام تغییر رمز به صفحه ورود هدایت می‌شوند (بررسی خودکار دوره‌ای + هنگام بازگشت به تب + پیش از ساخت هر کانفیگ یا لیست DNS).
- **محدودیت تلاش ناموفق (Rate Limiting):** جلوگیری از حدس رمز (Brute-Force) روی هر دو صفحه ورود.

## بازیابی در صورت فراموشی رمز ادمین

اگر رمز پنل ادمین را فراموش کردید:
1. وارد داشبورد Cloudflare → **Storage & Databases → KV** شوید و Namespace `AHOORA_KV` را باز کنید.
2. کلید `auth:admin` را حذف کنید.
3. دوباره به `/admin` بروید؛ رمز ادمین مجدداً به مقدار `INITIAL_ADMIN_PASSWORD` (یا پیش‌فرض `AT_ADMIN`) بازنشانی می‌شود.

## اجرای محلی (تست روی سیستم شخصی)

با Node.js نسخه ۱۸ به بالا (بدون نیاز به نصب پکیج اضافی):

```bash
npm run dev
```

سپس باز کنید:
- پنل اصلی: `http://127.0.0.1:8788/`
- پنل ادمین: `http://127.0.0.1:8788/admin`

برای اجرای تست‌های خودکار:

```bash
npm test
```

یا اجرای مستقیم با Wrangler CLI کلودفلر:

```bash
npm run cf:dev
```
